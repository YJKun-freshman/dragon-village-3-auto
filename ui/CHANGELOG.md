## v0.1.0 — 2026-11-06
### 新增
- 正式介面（customtkinter），照 `02_Tkinter外型.md` 的約定，可以直接取代 `app/fallback_ui.py`
- 版面：左右排（功能樹｜設定｜日誌）；配色 A 深色科技藍；所有顏色、字型、間距集中在 `theme.py`
- 功能樹（`ttk.Treeview` 自訂樣式）：依任務路徑自動產生；資料夾箭頭在右邊（▾／▸），點資料夾只會展開／收合，不會被選取；執行中不能切換任務
- 參數欄位依 `params` 動態產生：
  - `int`／`float` → 輸入框＋▲▼（也可用鍵盤上下鍵），即時檢查範圍，錯誤時紅框＋下方提示，開始鈕停用
  - `bool` → 勾選框；有 `choices` → 下拉選單；`str` → 輸入框
  - 有 `help` → 標籤旁的 ? 圖示，滑鼠移上去顯示說明
- **出招流程編輯器**（`widget="sequence"`）：步驟清單、選取的步驟可上移／下移／刪除、新步驟插在選取的步驟後面、
  「替換」「自動 N 回合」「回到第 N 步」用選單選；即時用 `validate` 檢查並顯示中文錯誤。
  步驟搬動或刪除時，「回到第 N 步」會自動跟著調整
- 設定區可捲動；開始／停止固定在底部
- **自動摺疊**：執行中或視窗寬度 < 1000 時，設定區縮成「摘要列」（任務名稱＋前 3 個參數＋開始／停止），日誌變寬；
  可按「展開參數」暫時打開；開始、停止或視窗寬度改變時恢復自動
- 日誌：時間用等寬字、警告黃字、錯誤紅字、換行後對齊時間後面；捲到最下面時才自動跟著捲；最多保留 3000 行
- 狀態列：遊戲連接（綠點／紅點）、執行狀態、進度、已執行時間
- 標題列：版本標籤、「日誌資料夾」（有 `on_open_logs` 才顯示）、「關於」
- 約定的方法全部可從背景執行緒呼叫（`queue.Queue` + `after()`）：`append_log`、`set_running`、`set_game_status`、
  `set_progress`、`get_values`、`request_start`、`request_stop`
- 切換任務時保留畫面上的內容（包括還沒改對的數字）；`get_values()` 只回傳正確的值
- 關閉視窗時如果還在執行，先呼叫 `on_stop()`
- `ui/demo.py`、`ui/demo.bat`：假任務＋假日誌的展示，不需要遊戲

### 需要新增的套件
- `customtkinter>=5.2`（已由本對話加進 `requirements.txt`，見 app v0.2.0）
- PyInstaller 打包要加 `--collect-data customtkinter`
