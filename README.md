# 龍村3 自動腳本

《龍村3》（Google Play 遊戲電腦版）的 Windows 自動腳本：自動戰鬥、自動釣魚。

- **背景操作**：不會移動你的滑鼠，遊戲可以被其他視窗擋住，或放在 Win+Tab 的另一個桌面
- 熱鍵 **F5 開始、F6 停止**（遊戲在其他桌面也有效，可在設定裡改）
- 支援 Windows 10／11、螢幕縮放 100%～150%

> ⚠ **免責聲明**：使用自動化程式可能違反遊戲或 Google Play 的使用條款，**帳號被處分的風險由使用者自行承擔**。本程式按「現狀」提供，作者不負任何責任。

## 下載與安裝

到右邊的 **Releases** 下載最新版本，兩種選一種：

### A. exe 版（一般使用者，推薦）
1. 下載 `dragon-village-3-auto_vX.X.X_exe.zip`
2. 解壓縮到任何資料夾（例如 `D:\龍村3自動腳本`）。**不要放在 `C:\Program Files`**，否則設定會改存到 `%APPDATA%\龍村3自動腳本\`
3. 雙擊 `龍村3自動腳本.exe`
4. 如果出現「Windows 已保護您的電腦」：按「**其他資訊**」→「**仍要執行**」（程式沒有數位簽章才會這樣）

### B. Python 版（已經有 Python、想看程式碼的人）
1. 安裝 [Python 3.11 以上](https://www.python.org/downloads/)（安裝時勾選「Add Python to PATH」）
2. 下載 `dragon-village-3-auto_vX.X.X_python.zip` 並解壓縮
3. 雙擊 `啟動.bat`（第一次會自動安裝需要的套件：opencv-python、numpy、customtkinter）

## 第一次使用

1. 打開 Google Play 遊戲電腦版和《龍村3》，**遊戲語言要是繁體中文**
2. 建議把遊戲視窗設成**直的（9:16）**；橫的（16:9）也可以，但遊戲畫面比較小
3. 視窗太小會辨識不準：遊戲畫面高度至少 600 像素
4. 打開本程式，下方狀態列出現「● 遊戲：已連接」就可以開始
5. 想邊跑邊做別的事：按 Win+Tab，把遊戲視窗拖到「新增桌面」，自己留在原本的桌面

> ❗ **遊戲視窗不能縮到最小**（縮到最小會截不到畫面）。要藏起來請用另一個桌面或用其他視窗蓋住。

## 功能

左邊選任務 → 中間調整參數 → 按「▶ 開始」或 F5。參數旁邊的 **?** 可以看說明。

### ⚔ 戰鬥
- **討伐戰**、**公會BOSS** 底下的項目可以自己新增、複製、改名、刪除（在項目上按右鍵）
- 每個項目有自己的**出招流程**，例如 `技能1 > 替換2 > 必殺技 > 自動`
- 討伐戰：體力不足時可以自動看廣告、用活力恢復劑或鑽石補體力
- 公會BOSS（公會戰役）：從公會戰役畫面開始，可選「挑戰」（一天一次）或「練習」

### 🎣 釣魚
- 可以從村莊、廣場或釣魚畫面開始，會自動走到釣魚場
- 自動拋竿、等上鉤、拉魚；魚餌用完可以自動看廣告補充

### ⚙ 設定
- 熱鍵：可以改開始／停止的按鍵
- 遊戲視窗：同時開好幾個遊戲時，選要操作哪一個（會記住）

## 常見問題

| 狀況 | 解決方法 |
|---|---|
| 防毒軟體說有病毒、把 exe 刪掉 | 自動化程式常被誤判。請把程式資料夾加入防毒軟體的「排除／白名單」 |
| 狀態列顯示「找不到遊戲視窗」 | 確認 Google Play 遊戲電腦版和《龍村3》已經打開 |
| 狀態列顯示「被縮到最小」 | 把遊戲視窗還原（可以放到其他桌面） |
| 一直找不到按鈕、辨識不準 | 把遊戲視窗拉大一點；確認遊戲語言是繁體中文 |
| F5／F6 沒反應 | 可能被其他程式佔用了，到 ⚙ 設定換一個熱鍵 |
| 要回報問題 | 在 ⚙ 設定按「日誌資料夾」，把當天的 `.log` 和截圖一起傳給作者 |

## 開發者

- `core/`：共用底層（找視窗、背景截圖、找圖、背景點擊），說明見 `core/README.md`
- `app/`：主程式整合；`ui/`：介面；`combat/`：戰鬥；`fishing/`：釣魚
- 截圖工具（裁樣板用）：雙擊 `capture.bat`
- 打包：雙擊 `打包.bat`，在 `dist\` 產生 exe 版和 Python 版兩個 zip
